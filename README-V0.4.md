# TG-WS-Proxy Android V0.4

Минималистичный центрированный тёмный интерфейс поверх рабочего ядра Flowseal.

Изменения V0.4:
- весь основной интерфейс центрирован по вертикали и горизонтали;
- заголовок расположен строго по центру, настройки доступны справа;
- статус и локальный endpoint аккуратно разделены по строкам;
- Telegram и Копировать сделаны собственными ровными action-блоками с отдельными иконками слева от текста;
- единая высота и отступы всех кнопок;
- Secret центрирован внутри карточки;
- сетевое ядро и диагностические возможности не изменены.
