# TG-WS-Proxy Android V0.3

Минималистичный тёмный интерфейс поверх рабочего ядра Flowseal 1.10.4.

Изменения V0.3:
- тёмная тема по умолчанию;
- минимум текста на главном экране;
- светло-серые основные кнопки;
- зелёный индикатор при работающем прокси;
- красный индикатор при выключенном прокси;
- жёлтый индикатор во время запуска;
- диагностика и debug log находятся только в разделе «Настройки»;
- сетевое ядро `proxy/` не изменено.
